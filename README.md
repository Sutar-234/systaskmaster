- **Languages:** C++17, C
- **Kernel Space:** Character Device Driver (LKM), `printk` telemetry, `module_param`[cite: 1]
- **User Space:** POSIX Daemons (`fork`/`setsid`), `sigaction` Signal Handling, POSIX Sockets[cite: 1]
